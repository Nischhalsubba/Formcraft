# ERP module definition of done

A Formcraft ERP module is not complete because a navigation item and create form exist. Every module must satisfy the following before being labelled production-ready:

1. Authoritative records and explicit lifecycle states
2. Company, branch, user and record-level permissions
3. Approval paths for controlled actions
4. Cross-module relationships with traceable source records
5. Idempotent side effects and duplicate prevention
6. Search, filters, grouping, list and board views
7. Comments, activities, files and audit events
8. Import, export, archive and data-retention behaviour
9. Empty, loading, saving, conflict, permission and failure states
10. Responsive keyboard-accessible UI
11. Calculations performed with appropriate monetary precision
12. Automated model, relationship, interaction and browser tests
13. Monitoring, reconciliation and rollback procedures
14. Nepal localisation and professional review for regulated workflows
15. No unqualified claim of government approval or equivalence with another product

The metadata-driven ERP suite provides this shared foundation. Specialist releases must deepen the domain logic for accounting, inventory valuation, manufacturing costing, payroll, public commerce, signature evidence, campaign delivery and regulatory integrations.
