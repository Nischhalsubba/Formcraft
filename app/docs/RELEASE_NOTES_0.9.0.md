# Formcraft 0.9.0 release notes

## Connected work records

Projects and tasks now use normal application record pages with stable URLs, browser-history support and persistent surrounding navigation. Large operational records are no longer treated as disposable popups.

## Jira-style work management

Tasks support stable keys, types, six workflow states, priorities, ownership, estimates, story points, billable status, labels, subtasks, dependencies, acceptance criteria, comments, checklist items and time entries. Projects provide list and board task views with filtering and drag-and-drop status changes.

## Cross-module reporting

Task completion updates project progress. Blocked and overdue work affects project health. Time and invoices update project operational and commercial summaries. Reports combine project delivery, budget, time, billed, paid and outstanding values.

## Safety and quality

Complex forms no longer dismiss on accidental backdrop or Escape actions. Viewer roles cannot mutate operational records. Circular dependencies and parent hierarchies are rejected. Production builds now run syntax, contract and model verification before Netlify can publish them.

## Honest boundary

This release delivers the connected project-delivery foundation. It does not claim complete Odoo parity or production implementation of CRM, purchasing, inventory valuation, double-entry accounting, Nepal payroll, helpdesk or a general automation engine.
