# Formcraft product direction

## Product pattern

Formcraft uses a calm operational workspace pattern. The interface is object-oriented around projects, tasks, people, events, files, and invoices. Working views prioritize lists, tables, ownership, deadlines, and clear status over decorative analytics.

## Visual language

- Warm neutral application canvas
- White working surfaces
- Graphite text
- Deep teal primary action color
- Restrained semantic colors
- Inter typography
- Borders instead of decorative shadows
- 8px controls, 12px cards, and 16px dialogs

## Dashboard hierarchy

1. Today: overdue and near-term tasks
2. Upcoming: meetings, reviews, and deadlines
3. Active projects: owner, status, progress, and due date
4. Compact operational summary
5. Recent activity and quick actions

## Form system

- Labels above fields
- 48px controls
- One-column mobile forms
- Two-column desktop layouts only for related fields
- Sticky action footer
- Visible validation and saving states
- Destructive actions separated from primary actions

## Anti-patterns

- Purple gradient SaaS styling
- Oversized KPI cards as the primary dashboard content
- Decorative charts without useful data
- Cards nested inside cards
- Low-contrast dark surfaces
- Fields that do not affect a real workflow
