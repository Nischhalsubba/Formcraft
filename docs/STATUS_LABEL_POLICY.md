# Feature status label policy

- **Planned**: documented direction only.
- **In development**: implementation exists on a branch but has not passed release gates.
- **Implemented**: code and persistence path exist.
- **Ready to test**: relevant automated checks pass.
- **Production ready**: automated checks, manual acceptance, deployment verification and rollback checks pass.

“Zero bugs” is not a valid engineering status. The practical target is no known release-blocking defect, automated regression coverage and observable recovery paths.
